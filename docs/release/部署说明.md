## 交付范围

执行 `npm ci` 后运行 `npm run build`，上传生成的 dist **内容**到站点根路径。无需服务端 API、数据库或云账户登录。当前只准备静态交付，未购买资源、改 DNS 或公开发布。

试运行可选香港静态托管加自有域名；大陆稳定可用的正式路线应使用已备案域名及同时覆盖大陆和海外的服务。服务商、账号、域名、预算和备案仍由指挥部确认。香港节点不能保证大陆所有网络可达。

## 托管配置

- 强制 HTTPS；本地 localhost/127.0.0.1 是浏览器开发例外。证书覆盖最终域名。
- 根路径 `/` 与 `/index.html` 返回 HTML；`/sw.js` 用 JavaScript MIME，禁止重定向到 HTML；manifest 用 `application/manifest+json`；图标用 image/png。
- `/index.html`、`/sw.js`、`/manifest.webmanifest` 建议 `Cache-Control: no-cache`；带内容哈希的 `/assets/*` 可用 `public,max-age=31536000,immutable`。非哈希图标使用 no-cache 或短缓存。
- 本版没有路径路由，无需将任意路径回退成 HTML；缺失 JS/CSS/图标必须返回 404，不能返回 index.html 假冒成功资源。未来增加路径路由后再单独配置文档导航回退。
- 不添加外部字体、统计、运行时 CDN、第三方脚本或 API。最终构建网络审计结果见验收报告。
- 同一域名、协议和端口对应同一浏览器存储；更换域名不能自动迁移记录，用户先从旧站导出、再到新站导入。

## 发布与回滚

1. 保存上一版 dist；每次发布前修改 sw.js 的 RELEASE，并完成 build、单元测试及 E2E。
2. 先上传哈希资源及图标，再上传 HTML/manifest，最后上传 sw.js；最好用托管平台原子切换目录。保留旧哈希资源，避免仍打开旧页的用户加载失败。
3. 在线打开后等待 service worker 安装完成，再断网重开验证签到、动作、计时、记录；首次访问前未缓存的设备不能离线打开。
4. 新 worker 会等待旧站全部标签页关闭，不主动打断正在进行的充电。用户关闭所有站点窗口后重开接收新版。
5. 回滚时恢复旧静态产物，但给 sw.js 新的 RELEASE 标记重新发布；不要清理 localStorage。先检查当前备份结构与回滚代码兼容性。

## 上线后必须补做

分别用中国大陆实际移动网络/宽带及海外网络检查 DNS、证书、首屏、静态文件、首次安装、离线重开和新版本更新；记录日期、地区、运营商、URL、结果。大陆可达性未验证，海外公网可达性未验证。本地通过不能替代公网测试。

iOS Safari、Android 真机添加到主屏幕、系统大字体、屏幕阅读器和锁屏/进程冻结需另行实测。本地数据可能随用户清理浏览器或系统回收而丢失，应保留导出入口。
